ブラウザで🐸を飼う

えさ（系列）をあげて、つまみを回して、予測の内訳をのぞいてみましょう。動いているのは pip install cse-frog と同じ本物のコードです。すべてあなたのブラウザの中で動き、何も送信しません。

準備しています…（初回は Python と numpy の読み込みで十数秒かかることがあります）

1えさをあげる

記号の区切り方

まだ何も覚えていません。

2つまみを回す

動かすと、同じえさで 🐸 を作り直して覚え直します。

3中をのぞく

🐸「次はたぶん 」

直接履歴並び痕跡右端の数字＝確率
数字で見る（frog.explain の中身）

続きを書かせる

「」から出ているつながり（frog.edges）

Python を書いて 🐸 をいじる

Frog と END は最初から使えます。「つまみで遊ぶ」で覚えさせた 🐸 は frog という名前で入っています。Ctrl+Enter（Mac は ⌘+Enter）でも実行できます。
